# Abstracta
Abstracta es una app de lectura con la misión de facilitar el acceso de papers para estudiantes e investigadores.

# Misión
La misión de Abstracta es democratizar la literatura científica. Buscamos diseñar un puente entre la complejidad académica y el aprendizaje eficiente, brindando a estudiantes e investigadores herramientas analíticas avanzadas en una interfaz intuitiva que optimiza la retención, la organización y la distribución del conocimiento.
